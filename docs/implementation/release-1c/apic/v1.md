## 1. Network Streaming Binary Socket Protocol (v1 Native — `--mode stream`)

Giao thức truyền luồng dữ liệu thời gian thực giữa Raspberry Pi 3 (Capture Node) và Laptop / Jetson AGX Xavier (Ingest Node) hoạt động trên tầng giao vận TCP/IP với độ trễ thấp nhất, tương thích nhị phân $100\%$ với `services/vision_pipeline/ingest_service.py` và `scripts/mock_ingest_server.py`.

### 1.1. Transport Layer Invariants & Dual-Interface Support
- **Giao thức:** TCP Socket với tùy chọn `TCP_NODELAY = 1` (tắt thuật toán Nagle) và cơ chế gửi nguyên tử `send_all()` có kiểm tra `poll(POLLOUT)` để đảm bảo không bao giờ gửi thiếu byte gây lệch khung (`framing desync`).
- **Default Port:** `9876` (TCP Binary Ingest Port).
- **Hỗ trợ Kép 2 Giao thức Vật lý (Wi-Fi & Wired Ethernet):**
  1. **Wi-Fi (`wlan0`):** Truyền luồng TCP tới Laptop (`--host <LAPTOP_WIFI_IP>`) phục vụ kiểm thử không dây linh hoạt.
  2. **Ethernet (`eth0` qua Hub chuyển đổi USB Type-C sang RJ45 với Laptop):** Hỗ trợ Zero-Friction Networking qua dải IP tự động APIPA (`169.254.x.x`), mDNS (`raspberrypi.local`), hoặc `--host <LAPTOP_ETH_IP>` mà không ép buộc cài đặt Static IP cố định trên máy tính cá nhân.
  3. **Ethernet (`eth0` nối trực tiếp Jetson AGX Xavier):** Truyền luồng TCP tốc độ cao tới `192.168.1.20:9876` khi tích hợp lên khung gầm Robot thực tế.
- **Đóng gói dữ liệu:** Contiguous Memory Block: `[PackedFrameHeader (40 bytes)] + [JPEG Payload Bytes]`.

### 1.2. Định Nghĩa Struct C++ Khung Header 40 Bytes (Strict-Aliasing Safe)

Cấu trúc Header được chuẩn hóa bằng định dạng C++17 thuần túy, căn chỉnh bộ nhớ chính xác từng byte (`#pragma pack(push, 1)`) và sử dụng `std::memcpy` để đóng gói số thực IEEE 754 (`float`) sang dạng `uint32_t` chuẩn Network Byte Order mà **không vi phạm quy tắc Strict Aliasing** khi biên dịch với cờ `-O3`:

```cpp
#ifndef PACKED_FRAME_HEADER_HPP
#define PACKED_FRAME_HEADER_HPP

#include <cstdint>
#include <cstring>
#include <arpa/inet.h>
#include <endian.h>

#pragma pack(push, 1)
struct PackedFrameHeader {
    uint16_t magic_be;         // Offset 0:  Magic bytes 0x5043 ('P', 'C') in Big-Endian
    uint16_t version_be;       // Offset 2:  Protocol version 1 in Big-Endian
    uint32_t frame_id_be;      // Offset 4:  Sequence Counter in Big-Endian
    uint64_t timestamp_ns_be;  // Offset 8:  Capture timestamp (ns) in Big-Endian
    uint32_t pitch_bits_be;    // Offset 16: IEEE-754 float32 pitch_deg bits in Big-Endian
    uint32_t roll_bits_be;     // Offset 20: IEEE-754 float32 roll_deg bits in Big-Endian
    uint32_t payload_len_be;   // Offset 24: JPEG payload size (bytes) in Big-Endian
    uint32_t width_be;         // Offset 28: Frame width (1280 or 640) in Big-Endian
    uint32_t height_be;        // Offset 32: Frame height (720 or 360) in Big-Endian
    uint32_t reserved_be;      // Offset 36: Reserved padding (0x00000000)
};
#pragma pack(pop)

static_assert(sizeof(PackedFrameHeader) == 40, "PackedFrameHeader size must be strictly 40 bytes!");

inline uint32_t pack_float_be(float value) noexcept {
    uint32_t raw_bits = 0;
    std::memcpy(&raw_bits, &value, sizeof(float)); // Strict-aliasing safe under -O3
    return htonl(raw_bits);
}

inline PackedFrameHeader make_packed_header(
    uint32_t frame_id,
    uint64_t timestamp_ns,
    float pitch_deg,
    float roll_deg,
    uint32_t payload_len,
    uint32_t width,
    uint32_t height) noexcept {
    PackedFrameHeader hdr{};
    hdr.magic_be        = htons(0x5043);
    hdr.version_be      = htons(1);
    hdr.frame_id_be     = htonl(frame_id);
    hdr.timestamp_ns_be = htobe64(timestamp_ns);
    hdr.pitch_bits_be   = pack_float_be(pitch_deg);
    hdr.roll_bits_be    = pack_float_be(roll_deg);
    hdr.payload_len_be  = htonl(payload_len);
    hdr.width_be        = htonl(width);
    hdr.height_be       = htonl(height);
    hdr.reserved_be     = 0;
    return hdr;
}

#endif // PACKED_FRAME_HEADER_HPP
```

### 1.3. Bảng Chi Tiết Bộ Nhớ & Chuyển Đổi Byte Order (`>HHIQffIIII`)

Mọi trường dữ liệu số nguyên và số thực khi gửi qua socket mạng đều được chuyển sang thứ tự byte chuẩn mạng (**Big-Endian**) khớp tuyệt đối với chuỗi `struct.unpack(">HHIQffIIII", buf)` phía Python:

| Trường (Field) | Kiểu dữ liệu gốc | Kích thước | Offset | Thứ tự Byte (Network Byte Order) | Hàm chuyển đổi C++17 an toàn (`-O3`) |
| :--- | :--- | :---: | :---: | :---: | :--- |
| `magic` | `uint16_t` | 2 bytes | 0 | Big-Endian (`0x50 0x43`) | `htons(0x5043)` |
| `version` | `uint16_t` | 2 bytes | 2 | Big-Endian (`0x00 0x01`) | `htons(1)` |
| `frame_id` | `uint32_t` | 4 bytes | 4 | Big-Endian | `htonl(frame_id)` |
| `timestamp_ns` | `uint64_t` | 8 bytes | 8 | Big-Endian | `htobe64(timestamp_ns)` |
| `pitch_deg` | `float` | 4 bytes | 16 | IEEE 754 Big-Endian | `pack_float_be(pitch_deg)` (`std::memcpy` + `htonl`) |
| `roll_deg` | `float` | 4 bytes | 20 | IEEE 754 Big-Endian | `pack_float_be(roll_deg)` (`std::memcpy` + `htonl`) |
| `payload_len` | `uint32_t` | 4 bytes | 24 | Big-Endian | `htonl(payload_len)` |
| `width` | `uint32_t` | 4 bytes | 28 | Big-Endian | `htonl(width)` |
| `height` | `uint32_t` | 4 bytes | 32 | Big-Endian | `htonl(height)` |
| `reserved` | `uint32_t` | 4 bytes | 36 | Big-Endian (`0x00000000`) | `0` |

## 2. HTTP MJPEG Preview & Telemetry API (`--mode preview`)

Để giữ nguyên phương thức kiểm thử trực quan qua Wi-Fi hoặc dây Ethernet nối Hub Type-C trên Laptop giống hệt bản Python (`services/pi_capture_agent/preview_server.py`), tiến trình C++ cung cấp Embedded HTTP Server nhẹ trên cổng mặc định `8080`:

| HTTP Endpoint | Method | Content-Type | Mô tả chức năng |
| :--- | :---: | :--- | :--- |
| `/` hoặc `/preview` | `GET` | `text/html; charset=utf-8` | Trang Web HUD hiển thị luồng video trực tiếp kèm góc nghiêng IMU (`pitch`, `roll`), tốc độ FPS và trạng thái phần cứng. |
| `/stream.mjpg` | `GET` | `multipart/x-mixed-replace; boundary=frame` | Luồng MJPEG liên tục (mặc định giảm chiều `640x360` bằng chỉ lệnh NEON, JPEG `Q=65`) để xem mượt mà qua Wi-Fi mà không cần cài phần mềm phía Laptop. |
| `/snapshot.jpg` | `GET` | `image/jpeg` | Trả về 1 khung hình JPEG tức thời để kiểm tra nhanh tiêu cự và góc gắn camera. |
| `/telemetry` | `GET` | `application/json` | Trả về JSON trạng thái thời gian thực: `{"frame_id": 120, "fps": 29.8, "pitch_deg": 1.25, "roll_deg": -0.40, "width": 640, "height": 360}`. |

## 3. Giao Diện Nội Bộ C++ (Internal C++ API Interfaces)

Module C++ phân tách các giao diện thành các lớp thuần túy (Pure Virtual Abstract Interfaces) để hỗ trợ mocking và unit test dễ dàng:

### 3.1. `ICameraDriver` (Media Controller + V4L2 MMAP + NEON De-interleave)
```cpp
struct PlanarYuv422Buffer {
    uint8_t* y_plane;          // 1280 * 720 bytes (or 640 * 360 in preview decimation)
    uint8_t* u_plane;          // (width / 2) * height bytes
    uint8_t* v_plane;          // (width / 2) * height bytes
    int width;
    int height;
    uint32_t sequence;
    uint64_t timestamp_ns;
};

class ICameraDriver {
public:
    virtual ~ICameraDriver() = default;
    // Tự động cấu hình Media Controller (/dev/media0 -> ov5640 10-003c),
    // mở /dev/v4l-subdev0 áp dụng V4L2_CID_VFLIP, và mở /dev/video0 MMAP
    virtual bool open(const std::string& video_dev,
                      const std::string& subdev_path,
                      int width, int height, int fps, bool vflip) = 0;

    // Thực thi poll(POLLIN) -> VIDIOC_DQBUF -> NEON vld2_u8 UYVY-to-YUV422P -> trả ngay VIDIOC_QBUF
    virtual bool capture_planar_yuv422(PlanarYuv422Buffer& out_planar, int timeout_ms = 100) = 0;

    virtual void close() = 0;
};
```

### 3.3. `IJpegEncoder` (`tjCompressFromYUV` + ARM NEON SIMD)
> **Lưu ý kỹ thuật quan trọng:** API `<turbojpeg.h>` không có hằng số `TJPF_UYVY` cho `tjCompress2()`. Do đó `IJpegEncoder` nhận các mặt phẳng `Y`, `U`, `V` (`YUV422P`) đã được tách bởi chỉ lệnh ARM NEON `vld2_u8` và gọi trực tiếp hàm `tjCompressFromYUV()` với `TJSAMP_422` và cờ `TJFLAG_FASTDCT | TJFLAG_NOREALLOC`.

```cpp
class IJpegEncoder {
public:
    virtual ~IJpegEncoder() = default;
    virtual bool encode_yuv422p(const uint8_t* y_plane,
                                const uint8_t* u_plane,
                                const uint8_t* v_plane,
                                int width, int height, int quality,
                                uint8_t* jpeg_out_buf,
                                unsigned long& jpeg_out_size) = 0;
};
```
