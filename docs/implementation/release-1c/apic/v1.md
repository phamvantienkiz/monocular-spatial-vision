## 1. Network Streaming Binary Socket Protocol (v1 Native)

Giao thức truyền luồng dữ liệu thời gian thực giữa Raspberry Pi 3 (Capture Node) và Jetson AGX Xavier / Laptop (Ingest Node) hoạt động trên tầng giao vận TCP/IP với độ trễ thấp nhất.

### 1.1. Transport Layer Invariants
- **Giao thức:** TCP Socket với tùy chọn `TCP_NODELAY = 1` (tắt thuật toán Nagle để đẩy gói tin ngay lập tức).
- **Default Port:** `9876` (TCP Ingest Port).
- **Default Server IP:** `192.168.1.20` (Jetson AGX Xavier) hoặc `192.168.1.100` (Laptop Developer).
- **Đóng gói dữ liệu:** Contiguous Memory Block: `[PackedFrameHeader (40 bytes)] + [JPEG Payload Bytes]`.

---

### 1.2. Định Nghĩa Struct C++ Khung Header 40 Bytes

Cấu trúc Header được chuẩn hóa bằng định dạng C/C++ thuần túy, căn chỉnh bộ nhớ chính xác từng byte (`#pragma pack(push, 1)`):

```cpp
#ifndef PACKED_FRAME_HEADER_HPP
#define PACKED_FRAME_HEADER_HPP

#include <cstdint>

#pragma pack(push, 1)
struct PackedFrameHeader {
    uint16_t magic;         // Magic bytes: 0x5043 ('P', 'C')
    uint16_t version;       // Protocol version: 1
    uint32_t frame_id;      // Số thứ tự khung hình tăng dần (Sequence Counter)
    uint64_t timestamp_ns;  // Mốc thời gian chụp phần cứng (Unix epoch nanoseconds)
    float    pitch_deg;     // Góc nghiêng trục Pitch từ IMU MPU6050 (độ, IEEE 754)
    float    roll_deg;      // Góc nghiêng trục Roll từ IMU MPU6050 (độ, IEEE 754)
    uint32_t payload_len;   // Độ dài mảng bytes JPEG đi liền kề phía sau
    uint32_t width;         // Chiều rộng khung hình (1280 hoặc 640)
    uint32_t height;        // Chiều cao khung hình (720 hoặc 360)
    uint32_t reserved;      // Trường dự phòng căn lề (0x00000000)
};
#pragma pack(pop)

static_assert(sizeof(PackedFrameHeader) == 40, "PackedFrameHeader size must be strictly 40 bytes!");

#endif // PACKED_FRAME_HEADER_HPP
```

### 1.3. Bảng Chi Tiết Bộ Nhớ & Chuyển Đổi Byte Order

Mọi trường dữ liệu số nguyên và số thực khi gửi qua socket mạng đều phải được chuyển sang thứ tự byte chuẩn mạng (**Big-Endian**):

| Trường (Field) | Kiểu dữ liệu | Kích thước | Offset | Thứ tự Byte (Network Byte Order) | Hàm chuyển đổi C/C++ |
| :--- | :--- | :---: | :---: | :---: | :--- |
| `magic` | `uint16_t` | 2 bytes | 0 | Big-Endian (`0x50 0x43`) | `htons(0x5043)` |
| `version` | `uint16_t` | 2 bytes | 2 | Big-Endian (`0x00 0x01`) | `htons(1)` |
| `frame_id` | `uint32_t` | 4 bytes | 4 | Big-Endian | `htonl(frame_id)` |
| `timestamp_ns` | `uint64_t` | 8 bytes | 8 | Big-Endian | `htobe64(timestamp_ns)` |
| `pitch_deg` | `float` | 4 bytes | 16 | IEEE 754 Big-Endian | `htonl(*((uint32_t*)&pitch))` |
| `roll_deg` | `float` | 4 bytes | 20 | IEEE 754 Big-Endian | `htonl(*((uint32_t*)&roll))` |
| `payload_len` | `uint32_t` | 4 bytes | 24 | Big-Endian | `htonl(payload_len)` |
| `width` | `uint32_t` | 4 bytes | 28 | Big-Endian | `htonl(width)` |
| `height` | `uint32_t` | 4 bytes | 32 | Big-Endian | `htonl(height)` |
| `reserved` | `uint32_t` | 4 bytes | 36 | Big-Endian (`0x00000000`) | `0` |

## 2. Giao Diện Nội Bộ C++ (Internal C++ API Interfaces)

Module C++ phân tách các giao diện thành các lớp thuần túy (Pure Virtual Abstract Interfaces) để hỗ trợ mocking và unit test dễ dàng:

### 2.1. `ICameraDriver`
```cpp
class ICameraDriver {
public:
    virtual ~ICameraDriver() = default;
    virtual bool open(const std::string& device, int width, int height, int fps) = 0;
    virtual bool capture_raw(uint8_t*& out_buffer, size_t& out_bytes, uint64_t& out_timestamp_ns) = 0;
    virtual void release_buffer() = 0;
    virtual void close() = 0;
};
```

### 2.2. `IImuDriver`
```cpp
struct ImuTelemetry {
    float pitch_deg;
    float roll_deg;
    float ax, ay, az;
    uint64_t timestamp_ns;
};

class IImuDriver {
public:
    virtual ~IImuDriver() = default;
    virtual bool init(int i2c_bus, uint8_t i2c_addr) = 0;
    virtual bool read_sample(ImuTelemetry& out_data) = 0;
};
```

### 2.3. `IJpegEncoder`
```cpp
class IJpegEncoder {
public:
    virtual ~IJpegEncoder() = default;
    virtual bool encode_uyvy(const uint8_t* raw_uyvy, int width, int height, int quality,
                             uint8_t* jpeg_out_buf, unsigned long& jpeg_out_size) = 0;
};
```

## 3. Đồng Bộ Với Tầng Tiêu Thụ Dữ Liệu ROS 2

Dữ liệu do Pi 3 truyền về khi được giải mã tại Jetson AGX Xavier sẽ được đưa trực tiếp vào Navigation Stack của robot thông qua ROS 2 C++ node (`rclcpp`):

- **`/perception/mono/objects_3d`:** `vision_msgs/msg/Detection3DArray` (Cung cấp hộp bao 3D cho Nav2 Costmap).
- **`/perception/mono/telemetry`:** `geometry_msgs/msg/Vector3Stamped` (Cung cấp góc nghiêng tức thời cho bộ lọc EKF Odometry).
