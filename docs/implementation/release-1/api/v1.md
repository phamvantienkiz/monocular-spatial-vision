## 1. Network Streaming Socket Protocol (v1)

### 1.1. Transport Layer Details
- **Protocol:** TCP (đảm bảo không mất mát gói tin telemetry) hoặc UDP Unicast với kiểm tra số thứ tự `frame_id`.
- **Default Port:** `9876` (TCP Stream Port).
- **Default Host (Ingest Server):** `192.168.1.20` (Jetson AGX Xavier).
- **Packet Structure:** Xem định nghĩa chi tiết tại [05-data-architecture.md](file:///E:/UIT/monocular-spatial-vision/docs/architecture/05-data-architecture.md#L1-L25).

## 2. ROS 2 Topic Specifications (v1)

Mọi message trong Release 1 đều được gắn tem thời gian `builtin_interfaces/msg/Time stamp` và frame quy chiếu `frame_id: "camera_optical_frame"`.

### 2.1. `/perception/mono/objects_3d`
- **Type:** `vision_msgs/msg/Detection3DArray`
- **Fields:**
  - `header`: Chuẩn ROS 2 header.
  - `detections[]`:
    - `results[0].hypothesis.class_id`: ID chủng loại vật thể (0: Person, 56: Chair, 60: Table...).
    - `results[0].hypothesis.score`: Độ tin cậy nhận diện ($0.0 - 1.0$).
    - `bbox.center.position`: Tọa độ $[X, Y, Z]$ trong không gian quang học (đơn vị: mét).
    - `bbox.size`: Kích thước $[L, W, H]$ (đơn vị: mét).

### 2.2. `/perception/mono/telemetry`
- **Type:** `geometry_msgs/msg/Vector3Stamped`
- **Fields:**
  - `vector.x`: Góc pitch hiện thời $\theta$ (độ).
  - `vector.y`: Góc roll hiện thời $\phi$ (độ).
  - `vector.z`: Chiều cao camera hiện thời $h_c$ (mét).
